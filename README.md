Miles Yamner, CPSC490 Final Project: Probabilistic Forecasting of S&P 500 Stocks Using Conditioned Normalizing Flows.


This project explores the applications of CNFs to learning S&P 500 stock forecasts, based on the framework proposed [here](https://github.com/zalandoresearch/pytorch-ts/tree/master). Additionally, baseline models and evaluation metrics are implemented to test efficacy.
